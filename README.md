# Focus-Blocker
A website blocker browser extension for Microsoft Edge.
# 100% vibe-coded!!!

# Installation
1. Download *focus-blocker.zip* and unzip the file
2. Open Edge browser and go to: <ins>edge://extensions</ins>
3. Turn on **Developer mode** (toggle in the bottom-left)
4. Click **Load unpacked** (button on the right) and select the unzipped *focus-blocker* folder
